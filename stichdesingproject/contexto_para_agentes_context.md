# Configuración de Contexto para Agentes: PiczaDev

## 1. Visión del Proyecto
PiczaDev es una plataforma personal que fusiona la identidad de un desarrollador Web3 con un ecosistema de creación de contenido (Blog y Newsletter). La marca busca transmitir innovación técnica, fluidez y un estándar de diseño premium ("Liquid Glass").

## 2. Personalidad de Marca
- **Vanguardista:** Enfoque en Inteligencia Artificial y protocolos descentralizados.
- **Fluida:** Estética inspirada en el vidrio líquido y la refracción de luz.
- **Minimalista:** Menos es más, pero con vitalidad a través del color neón y auras.

## 3. Elementos Visuales Clave (Design Tokens)
- **North Star:** "The Ethereal Forge" (La Fragua Etérea).
- **Colores:** Fondos negros profundos (`#000000`), acentos cian (`#69daff`) y púrpura (`#ac89ff`).
- **Efectos:** Glassmorphism extremo (blur de 40-60px), bordes refractivos y sombras de aura vibrantes.
- **Tipografía:** Plus Jakarta Sans (bold para titulares, medium para lectura).

## 4. Estructura de Navegación
1. **Landing Page:** Hub central y marca personal.
2. **Dashboard:** Visualización de actividad on-chain y transacciones.
3. **Blog:** Repositorio de conocimientos y artículos técnicos.
4. **Newsletter:** Canal de comunicación directa y suscripción orgánica.

## 5. Instrucciones para el Agente
Al generar nuevo contenido o código para este proyecto:
- Priorizar la legibilidad en interfaces oscuras.
- Utilizar gradientes `text-gradient-primary` para elementos destacados.
- Mantener la coherencia con el sistema de diseño **Liquid Obsidian**.
- Asegurar que todos los componentes sean totalmente responsivos.
